# Plan 02: Threshold Integration for Badges & HOD Department At-Risk Dashboard

## Objective
Integrate department custom thresholds into mentor student evaluation (ALERT-02) and build department-wide aggregated at-risk student metrics and severity breakdowns on the HOD dashboard using active department thresholds (ALERT-03).

## must_haves
- [ ] Mentor student list and student detail views (`src/server/alerts/attention.ts`) fetch and apply department custom thresholds (falling back to `ALERT_CONFIG` system defaults).
- [ ] HOD dashboard (`src/server/db/coverage.ts` and `src/components/DepartmentDashboardClient.tsx`) computes and displays department-wide at-risk student counts and severity breakdowns (High, Medium, Low) using department thresholds without exposing confidential notes or individual student records.
- [ ] Unit and integration tests covering custom thresholds, backward-compatible default alert evaluation, and HOD metric calculations.
