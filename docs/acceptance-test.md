# Faculty acceptance test

This protocol is ready to run. It is not evidence that a real faculty or phone test has happened.

## Preparation

Use the synthetic demonstration dataset and a basic Android phone over HTTPS. Confirm the mentor has 20 mentees. Use test notes, not real student information. Record device/browser, network, provider/model, language, participant and build date. Make sure the microphone permission, installation and login work before the timed test. Reset test progress in a separate disposable database if you need a fresh run; do not reset production data.

## Ten-minute task

Start a stopwatch when the mentor opens This Week. Ask them to review all 20 mentees, open the evidence, and explicitly mark each reviewed. Ask them to record three conversations: one English, one Tamil, and one Tamil-English mixed note. For each, review the transcript, create and edit a draft, confirm an agreed action and date, and save. Stop when the third confirmed meeting appears in the history. The target is under ten minutes. Record elapsed time, corrections, errors and assistance; do not substitute automated test timing for faculty timing.

## Speech benchmark

Use at least five short consented test clips in each language category. Include names, subjects, numbers and relative dates. Record transcription latency and errors that alter meaning, then compare summary/action/date extraction with a human reference. Dates unsupported by the resolver should stay blank. Include a microphone denial, silence, network loss and provider failure. Do not claim Tamil accuracy from mocked providers.

## Privacy and follow-ups

Sign in as the student and confirm only their confirmed notes and agreed actions appear. Complete a test action, then check mentor pending items, overdue alerts and department counts after refresh. Try another student's URL and another mentor's export. The department page and its API must not contain student names, roll numbers, notes or action text. Include a student with two mentor assignments to verify the coverage denominator remains distinct students.

## Phone and PWA

Install the app, reopen it from the home screen, use portrait/landscape and the software keyboard, and inspect the bottom tabs around the home indicator. Check text in daylight, 48px controls, microphone permissions and scrolling on actual hardware. Go offline: a public offline screen should appear on navigation; authenticated pages/API responses must not appear in Cache Storage. Keep an unsaved note tab open, reconnect and save it. Closing a tab is not a supported draft-recovery path.

## Registers and reports

Download Word/Excel with empty and populated date ranges. Verify every action, date and completion status. For reports, open Print / save PDF and inspect the output. Compare the mentoring register against one actual supplied college sample once available; the current general format does not fulfill an exact sample-match acceptance criterion.

## Evidence to retain

Keep the timed observation sheet, consented clip scores, device details, redacted screenshots and approved sample exports. Note failures and retest after fixing them. No real faculty, speech accuracy or real-device result is claimed until this evidence exists.
